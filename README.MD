# Food Villa — React Food Ordering App

A **fully tested**, **production-ready** Single Page Application (SPA) built using **React**, **React Router DOM**, **Redux Toolkit**, and more. Inspired by Swiggy, this app follows the **DRY principle** and modern frontend best practices.

---
## 🚀 Live Demo
👉 **[View Live Here](https://foodvill.netlify.app/)**

---

## Features

Fully component-driven SPA using React  
Dynamic routing using React Router DOM  
Restaurant listing with responsive card layout  
View full menu and details on restaurant click  
Real-time search filtering by restaurant name  
Shimmer UI loading effect for better UX  
**Global state management** with Redux Toolkit  
**Context API** for user-related data  
**Custom hooks** (e.g., online status detection)  
Clean, modular, and maintainable codebase  
100% **unit-tested UI components** with Jest & React Testing Library  

---

## Architecture

- **DRY (Don't Repeat Yourself)** principle applied across components
- **Presentational + Container Component pattern**
- State managed globally via **Redux Toolkit slices**
- Local, testable side effects using **custom hooks**

---

## How to Run Locally

1. **Clone the repo**

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the dev server**
   ```bash
   npm run dev
   ```

4. **Run tests**
   ```bash
   npm run test
   ```
