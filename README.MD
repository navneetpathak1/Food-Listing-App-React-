A **Single Page Application (SPA)** built with **React** and **React Router DOM**, inspired by Swiggy.  
The app displays restaurants as cards and allows users to click and view dynamic menus, all without page reloads.

---

## Features

✅ Single Page Application using React  
✅ Dynamic routing with React Router DOM  
✅ Restaurant listing with card layout  
✅ Click a restaurant to view its menu and details  
✅ Search restaurants by name  
✅ Shimmer loading placeholder  
✅ Clean component-based architecture
